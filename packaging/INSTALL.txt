LIMINAL - Cinematic Environmental Instrument (macOS, Apple Silicon and Intel, macOS 10.15+)
Milestone 1a: Forgotten Piano, Faded Synth and Glass Memories, one room-tone ambience. Not the final look.

INSTALL
  1. Quit GarageBand and Logic.
  2. Open Terminal (Applications > Utilities > Terminal).
  3. Type "bash " (with a space), drag install-mac.sh from this folder into the
     Terminal window, and press Return.
  4. Wait for "LIMINAL is installed and validated."

  Why a script? This build is not signed with an Apple Developer ID. When a browser
  downloads it, macOS marks every file as quarantined and then refuses to load the
  plug-in: GarageBand shows a silent slot with plain sliders. The script removes that
  flag, re-signs the plug-in for this Mac, refreshes the Audio Unit list and runs
  Apple's validator.

GARAGEBAND
  Settings > Audio/MIDI: tick "Audio Units". Restart GarageBand.
  Track > New Track > Software Instrument. Smart Controls (B) > Plug-ins >
  Instrument slot (top) > AU Instruments > Veil Audio > LIMINAL.
  The room ambience plays straight away while the track is selected. Play notes
  (MIDI keyboard, or Window > Show Musical Typing) to hear the Forgotten Piano.
  INSTRUMENTS (bottom strip) opens a drawer: switch the Faded Synth and Glass
  Memories on (MIDI plays every instrument that is on), set levels, edit each one.
  If you see sliders instead of the LIMINAL interface, switch the plug-in
  window's view menu from "Controls" to "Editor".

LOGIC PRO
  Settings > Plug-in Manager > Veil Audio > LIMINAL. If it is marked failed,
  select it and click "Reset & Rescan Selection". Insert it in the Instrument slot
  of a Software Instrument track: AU Instruments > Veil Audio > LIMINAL.

UNINSTALL
  bash uninstall-mac.sh            (add --purge to also delete saved presets)

MANUAL INSTALL (if you prefer not to run the script)
  cp -R LIMINAL.component ~/Library/Audio/Plug-Ins/Components/
  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/LIMINAL.component
  codesign --force --deep --sign - ~/Library/Audio/Plug-Ins/Components/LIMINAL.component
  killall -9 AudioComponentRegistrar
  auval -v aumu Lmnl Veil
