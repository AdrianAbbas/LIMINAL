# Architecture

`Parameters` is an append-only stable ID/range registry shared by JUCE, the engine, factory presets and tests. The processor snapshots atomics once per block, then consumes MIDI at sample offsets. DSP timing uses sample count, never wall time. Voices and resonators use fixed arrays. Delay memory is allocated in prepare. No DSP file I/O, mutex, or heap allocation is intended in processBlock; preset file dialogs and serialization run outside it. APVTS state copying/restoration follows the JUCE host API.

Electrical combines mains sine harmonics, band-limited buzz and random smoothed flicker. Ventilation combines low-pass airflow, rotational amplitude modulation, fan motor harmonics and low rumble. Structure excites six decaying, inharmonic sinusoidal modes with exponentially distributed event spacing and a minimum interval. Atmosphere mixes spectrally shaped noise, diffuse tones and bounded slow modulation. Distant activity is a separately scheduled decaying impact/machine tone with low-pass muffling. Substructure provides low oscillation, harmonics and a free or tempo-synchronized pressure pulse. These are physically inspired synthesis models, not recordings or an exact simulation of specific machinery.

MIDI supplies a shared eight-voice harmonic bank to tonal layers. Stealing preserves envelope and phase, though the frequency jump is not a legato pitch glide. Layer enables and most values use 35 ms one-pole smoothing. MIDI attack/release are exponential times (not the time to mathematical zero). Voice release terminates below a small threshold.

The room uses six geometry-derived early-reflection taps and eight delay lines with a Householder feedback matrix, RT60-derived feedback and material-dependent low-pass absorption. Delay reads interpolate while dimensions change. Source distance changes direct attenuation and high-frequency loss. Source/listener separation changes reflection timing; graphics show schematic paths, not measured rays. The model intentionally trades physical accuracy for predictable cost. The scale macro changes room timing and RT60; it does not resize the displayed metre values.

A seeded xorshift generator drives bounded interpolated stochastic targets and exponential event scheduling. Freeze stops modulation target/timing progression and new events, but oscillators, envelopes, filter state and acoustic tails continue. Seed changes and Reset Evolution clear the complete engine, including active voices/tails; reset is an explicit discontinuity, best used stopped. Reset clears preallocated delays in the callback and may be costly for very small blocks; it is not intended for rapid automation. Equivalent preset/seed/initialization/sample timing reproduces DSP output. Session restore restarts the sequence; transient sample/voice/delay state is not serialized.

Output uses a sample-rate-aware low cut (also rejects DC), high cut, mid/side width, smoothed level/mute and bounded tanh protection. The soft protector is not oversampled: the normal signal chain is gain-staged well below its knee; intentionally extreme overload may add aliased harmonics. No claim of mastering limiter transparency is made. No independent nonlinear distortion stage is used.

A/B stores atomic parameter arrays. Continuous environmental parameters are interpolated, with a shared live stochastic engine. Edits while capturing/restoring are not a transaction across the full array and could briefly expose intermediate values; smoothing limits continuous transitions. Scenes are intended for message-thread capture rather than rapid simultaneous editing from several controllers.
