# Instrument / ambience gain staging (0.2.1)

## Audit

The 0.2.0 musical path multiplied model partials by the exponential voice envelope,
linear MIDI velocity, a conservative 0.18 reference gain, the family level (0.65
by default), and equal-power stereo placement (0.707 per side). All of that then
entered the same room input as the ambience. Source distance applied approximately
-4.7 dB at the default 12 m, reverb reduced the direct path by another 3.7 dB at
50% mix, and the common master added -9 dB. Individual Distance controls added
further attenuation. This combination was too conservative for a foreground
instrument. Different models also had different intrinsic RMS levels.

Presence was applied to ambience before the musical input was added; it was not
the instrument attenuation bug. It remains independent of isolated musical level.

## Revised routing

- Voice velocity/envelopes, user family levels and -9 dB master default remain.
- Family reference trims: piano 1, synth 1.1, glass 1, choir 1.8, music box 1.3,
  drone 2.2. These align moderate-velocity phrase levels without flattening
  dynamics with an automatic gain rider.
- Layer summing compensates by inverse square root of enabled family power;
  zero-level families do not reduce the other instruments' level. This is
  inter-family headroom management, not a per-note loudness normaliser.
- The musical bus has a sixfold reference calibration, then the new automatable
  **Instrument Level** fader (-60 to +6 dB, default 0). -60 mutes new musical input.
- A 75% musical direct path preserves a foreground source. A 25% send still feeds
  the architectural room; source distance no longer attenuates the entire bank.
- Ambience has its own **Ambience Level** fader (-60 to +6 dB, default -12), before
  the room. Factory defaults use -12 to -15 dB according to the ambience profile.
  Turning it down does not raise or lower the instrument direct path.
- Both paths retain Active/transport fades, output filters, master gain and width.
  The bounded soft protector has a 0.89 linear ceiling (about -1 dBFS). It is not
  a transparent oversampled mastering limiter. Existing room tails decay naturally
  after bus input is muted.

The two global faders are always visible in the header. State schema 3 appends
stable IDs `instrumentBusLevel` and `ambienceBusLevel`. Versions 1 and 2 migrate
missing bus settings to the new defaults; stored legacy master/layer values remain.

## Verification

`gain_tests` renders the actual Instruments + Engine routing at 48 kHz using the
same fixed eight-second two-chord phrase at velocity 0.8. Each of the six families
is tested alone and mixed with all six ambience layers for defaults, Mall,
Hospital and Industrial presets. Independent post-output musical/ambience stems
produce peak/RMS measurements, reported as `build/BALANCE_REPORT/gain-staging.csv`.
The CSV is generated by the current test run, not a hand-entered report.

Regression requirements: each default phrase exceeds -36 dBFS RMS, instrument
RMS is at least 12 dB above the corresponding ambience, and normal mixed phrases
retain 3 dB peak headroom. Separate checks test the 6 dB instrument-fader mapping,
Presence isolation, finite output, and maximum-velocity 72-voice layering with a
-1 dBFS safety ceiling and RMS below -10 dBFS. Thresholds establish usable signal
levels/headroom; they do not prove subjective sound quality or masking immunity
for every MIDI performance.

The initial revised render comparison measured approximately 18–29 dB musical
foreground advantage, with family phrase RMS around -26 to -32 dBFS. A 72-voice
stress chord measured -4.51 dBFS peak / -18.20 dBFS RMS. The committed CSV from the
final run records the per-preset calibration. Listening feedback from GarageBand
is still needed; numerical balance does not certify musical realism.
